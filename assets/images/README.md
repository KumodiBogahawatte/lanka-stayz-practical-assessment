# Local image assets

Photographs are stored locally as responsive 960- and 1280-pixel JPEG variants. Destination and landmark photos are reserved for the homepage hero and editorial/page-header imagery. Listing cards and property-detail galleries use the Sri Lankan accommodation photos below as representative references; these photos do not depict the fictional sample listings. Visible labels, image alt text, and lightbox captions identify them as representative.
